# 音频资源说明

## 目录结构

```
audio/
├── bg-music.mp3          # 背景音乐（古风音乐）
├── seasons/              # 节气音效
│   ├── spring.mp3       # 春季音效
│   ├── summer.mp3       # 夏季音效
│   ├── autumn.mp3       # 秋季音效
│   └── winter.mp3       # 冬季音效
└── voice/               # 语音朗读
    ├── lichun.mp3       # 立春朗读
    ├── jingzhe.mp3      # 惊蛰朗读
    └── ...              # 其他节气朗读
```

## 音频规格

- **格式**: MP3
- **码率**: 128kbps
- **采样率**: 44.1kHz
- **声道**: 立体声

## 使用说明

1. 将音频文件放入对应目录
2. 在组件中取消音频相关代码的注释
3. 确保文件路径正确

## 临时方案

当前使用Web Speech API进行语音合成，无需音频文件。
